# Kế hoạch Refactor dự án ShareDocu

## Tổng quan

Kế hoạch này chia các công việc refactor thành 5 phiên làm việc, mỗi phiên tập trung vào một nhóm vấn đề cụ thể để đảm bảo hoàn thành trọn vẹn trong khoảng thời gian hợp lý (2-3 giờ/phiên).

---

## Phiên 1: Bảo mật khẩn cấp (Critical Security Fixes)

**Thời gian dự kiến:** 2.5 giờ  
**Mức độ ưu tiên:** 🔴 Critical

### Công việc:

1. **Cài đặt và cấu hình EncryptedStorage** (45 phút)
   - Cài đặt `react-native-encrypted-storage`
   - Tạo wrapper utility `src/utils/secureStorage.ts`
   - Migration token từ AsyncStorage sang EncryptedStorage

2. **Refactor AuthContext sử dụng EncryptedStorage** (45 phút)
   - Thay thế `AsyncStorage` bằng `EncryptedStorage` trong `AuthContext.tsx`
   - Cập nhật logic login/logout/updateUser
   - Test luồng đăng nhập/đăng xuất

3. **Tách biến môi trường (Environment Variables)** (60 phút)
   - Kiểm tra `.gitignore` đảm bảo `.env` không bị commit
   - Cấu hình `react-native-dotenv` cho nhiều môi trường
   - Tạo file `.env.example` làm template
   - Cập nhật `src/config/env.ts` sử dụng biến môi trường

### Lý do ưu tiên:

- Lỗ hổng bảo mật lưu trữ token là rủi ro lớn nhất
- Hardcoded API URL có thể gây sự cố production ngay lập tức
- Đây là nền tảng cho tất cả các tính năng khác

## Phiên 2: API Client & Error Handling

**Thời gian dự kiến:** 2.5 giờ  
**Mức độ ưu tiên:** 🟠 High

### Công việc:

1. **Xây dựng API Client chung** (60 phút)
   - Tạo `src/api/client.ts` với hàm `apiCall` thống nhất
   - Xử lý headers tự động (Authorization, Content-Type)
   - Xử lý response status codes (401, 403, 500, network errors)
   - Implement retry mechanism cơ bản

2. **Tạo TypeScript Interfaces** (45 phút)
   - Định nghĩa `Document`, `User`, `ApiResponse` trong `src/types/index.ts`
   - Loại bỏ `any` types trong các file chính
   - Cập nhật type cho navigation props

3. **Refactor ScannerScreen API calls** (45 phút)
   - Sử dụng API client mới thay vì fetch trực tiếp
   - Áp dụng interfaces đã định nghĩa
   - Cải thiện error messages

### Lý do ưu tiên:

- Giảm code trùng lặp ở tất cả các màn hình
- Cải thiện khả năng debug và maintain
- Tạo nền tảng cho các phiên sau

## Phiên 5: UX Improvements & Polish

**Thời gian dự kiến:** 2.5 giờ  
**Mức độ ưu tiên:** 🔵 Low

### Công việc:

1. **Network Status Detection** 
   - Cài đặt `@react-native-community/netinfo`
   - Tạo hook `src/hooks/useNetworkStatus.ts`
   - Hiển thị banner khi mất mạng
   - Disable actions khi offline

2. **Accessibility Improvements** 
   - Thêm `accessibilityLabel` cho tất cả TouchableOpacity
   - Thêm `accessibilityHint` cho nút quan trọng
   - Đảm bảo contrast ratio đạt chuẩn WCAG
   - Test với Screen Reader

3. **Constants & Cleanup**
   - Tạo `src/constants/app.ts` cho magic numbers
   - Di chuyển COLORS vào theme chung
   - Xóa console.log thừa
   - Format code với Prettier

### Lý do ưu tiên:

- Cải thiện trải nghiệm người dùng
- Đáp ứng tiêu chuẩn accessibility
- Dọn dẹp codebase sau refactor

## Điều chỉnh kế hoạch

### Nếu thiếu thời gian:

- **Gộp Phiên 3 & 4:** Chỉ refactor ScannerScreen (quan trọng nhất), defer ShareForm
- **Bỏ qua Phiên 5:** Các cải thiện UX có thể làm sau, không blocking

### Nếu có thêm nguồn lực:

- **Parallelize:** Giao Phiên 3 cho developer khác trong khi làm Phiên 2
- **Accelerate:** Hoàn thành sớm hơn 1-2 ngày

### Nếu phát sinh vấn đề mới:

- Ưu tiên vẫn giữ nguyên: Security > Architecture > Refactor > UX
- Đánh giá mức độ critical của issue mới và chèn vào vị trí phù hợp

---

## Rủi ro & Giảm thiểu

1. **Rủi ro:** EncryptedStorage có thể gây sự cố trên một số thiết bị cũ
   - **Giảm thiểu:** Test kỹ trên Android emulator và physical device trước khi deploy

2. **Rủi ro:** Refactor lớn có thể introduce bugs
   - **Giảm thiểu:** Test manual từng bước, commit nhỏ thường xuyên

3. **Rủi ro:** Thiếu thời gian
   - **Giảm thiểu:** Tập trung vào Phiên 1-2 (critical), defer các phiên sau

## Success Criteria

- ✅ Token được lưu trữ an toàn với EncryptedStorage
- ✅ Không còn hardcoded URLs
- ✅ API client thống nhất, loại bỏ fetch trực tiếp
- ✅ TypeScript interfaces đầy đủ, giảm `any` xuống <5%
- ✅ ScannerScreen <500 dòng, ShareFormScreen <500 dòng
- ✅ Input validation cho tất cả user inputs
- ✅ Network status detection hoạt động
- ✅ Accessibility score cải thiện (test với Lighthouse nếu có web view)
