### Nhiệm vụ 2.2: Tạo API Client

**Thời gian:** 45 phút  
**Đầu vào:** `src/config/env.ts`, `API_URL`  
**Đầu ra:** `src/api/client.ts`

**Các bước:**

1. Tạo `src/api/client.ts`
2. Implement các hàm:
   - `apiCall<T>` - Generic API call với headers tự động
   - `getAuthToken()` - Lấy token từ AuthContext
   - Handle 401, 403, 500 errors
   - Network error handling
3. Export clean API

**API Structure:**

```typescript
export async function apiCall<T>(
  endpoint: string,
  options?: RequestInit,
): Promise<T>;

export async function apiGet<T>(endpoint: string, token?: string): Promise<T>;

export async function apiPost<T>(
  endpoint: string,
  data?: any,
  token?: string,
): Promise<T>;
```
